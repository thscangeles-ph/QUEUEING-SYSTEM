Libraries used by the DICOM Viewer (public/dicom-viewer.html), unmodified except where noted.

dicomParser.min.js       dicom-parser 1.8.21 (npm), MIT, see dicomParser.LICENSE.txt
                         (source map comment removed)
jpeg-lossless.min.js     jpeg-lossless-decoder-js 2.0.7 (npm, release/current/lossless-min.js), MIT,
                         see jpeg-lossless.LICENSE.txt
openjpegwasm_decode.*    @cornerstonejs/codec-openjpeg 1.2.4 (npm, dist/), MIT; a WebAssembly build of
                         OpenJPEG, BSD 2-clause, https://github.com/uclouvain/openjpeg/blob/master/LICENSE
charlswasm_decode.*      @cornerstonejs/codec-charls 1.2.3 (npm, dist/), MIT, see charls-codec.LICENSE.txt;
                         a WebAssembly build of CharLS, BSD 3-clause, https://github.com/team-charls/charls
libjpegturbo12wasm.*     @cornerstonejs/codec-libjpeg-turbo-12bit 0.4.7 (npm, dist/), ISC; a WebAssembly build of
                         libjpeg-turbo with 12-bit support, IJG and BSD 3-clause licences,
                         https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/LICENSE.md
libde265.mjs, .wasm      @yume-chan/libde265 1.0.0 (npm), unmodified: a WebAssembly build of libde265, the HEVC decoder,
                         LGPL-3.0 (see libde265.COPYING.txt, which holds the LGPL and GPL texts). Source:
                         https://github.com/yume-chan/libde265 (build) and https://github.com/strukturag/libde265.
                         It is loaded as a separate file and can be replaced with another build of the same version.
